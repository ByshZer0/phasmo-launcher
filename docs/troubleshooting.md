# 常见问题

## 检测不到 Steam

**现象**：Steam 状态卡显示「未找到」。

**排查**：

1. 确认 `steam.exe` 存在。
2. 点「浏览」，选择 Steam 根目录，例如 `D:\Steam`，而不是 `D:\Steam\steamapps`。
3. 如果 Steam 是便携版或被移动过，注册表可能仍指向旧路径；请手动选择。
4. 点「重新检测」。

程序也会尝试 `%ProgramFiles(x86)%\Steam`、`%ProgramFiles%\Steam` 和 `C:\Steam`。

## 检测不到恐鬼症

**现象**：Steam 已就绪，但游戏显示「未检测到」。

**排查**：

1. 在 Steam 库中确认游戏已安装，且不只是“已购买”。
2. 打开游戏安装目录，确认存在 `Phasmophobia.exe`。
3. 如果游戏在第二个 Steam 库，确认该库的 `steamapps/libraryfolders.vdf` 存在且可读。
4. 游戏目录被手动改名时，`appmanifest_739630.acf` 里的 `installdir` 可能已失效；可在
   Steam 中「验证游戏文件完整性」。

程序只把 `Phasmophobia.exe` 存在视为已安装，避免在文件损坏时发出启动请求。

## 加速器启动了，但游戏延迟没变化

这是使用中最容易误解的一点：**启动器不提供加速线路**。

请检查：

1. 是否已经在加速器客户端中为 **Steam** 和 **恐鬼症** 分别开启加速。
2. 加速器是否需要管理员权限；如果需要，请以管理员身份运行启动器。
3. 加速器是否要求先启动 Steam 再选择游戏；如果是，把启动顺序改为「先 Steam，后加速器」。
4. 等待时间是否足够。加速器刚启动时可能还没连上节点，建议 15–30 秒。
5. 加速器客户端是否被最小化到托盘后暂停工作；查看其连接状态。

启动器只做进程编排，不修改 hosts、系统代理、路由或网卡设置。

## 选了加速器快捷方式，但参数不生效

`.lnk` 通过 Windows Shell 打开，无法附加命令行参数。请改选加速器主程序 `.exe`。

## 提示“请选择 .exe、.com 或 .lnk 文件”

出于安全考虑，启动器不会执行 `.bat`、`.cmd`、`.ps1` 等脚本作为加速器入口。
请选择加速器官方 exe，或创建指向该 exe 的快捷方式。

## 协议 URL 无法启动

`uu://` 这类协议需要对应客户端注册。若系统没有注册，Windows 会弹出“选择应用”或
直接报错。此时请改用 exe 路径。

## Steam 启动超时

默认等待 60 秒。以下情况会超时：

- 首次登录 / 需要邮箱验证码 / Steam Guard
- Steam 正在更新
- 网络断开
- Steam 被安全软件拦截

先手动启动 Steam 并完成登录，再使用启动器。Steam 已经在运行时，启动器会跳过启动步骤。

## 点击一键启动没有反应

- 查看「运行日志」中的错误。
- 确认没有另一个启动流程正在执行（按钮会短暂禁用）。
- 用 `python main.py --debug` 启动，查看控制台和日志文件。
- 检查加速器路径是否仍存在；移动过的 exe 会预检失败。

## 界面字体太小 / 模糊

程序在 Windows 上启用了 DPI 感知。若仍模糊：

- 右键 `python.exe` 或打包后的 exe → 属性 → 兼容性 → 更改高 DPI 设置；
- 或在 Windows「设置 → 显示 → 缩放」中调整比例后重启程序。

## 打包后的 exe 被 SmartScreen 拦截

exe 未做代码签名，Windows 会提示“已保护你的电脑”。选择「更多信息 → 仍要运行」。
正式分发建议使用代码签名证书签名。

## 配置文件损坏

程序读取失败会自动使用默认配置，不会崩溃。可以删除：

```text
%APPDATA%\PhasmoLauncher\config.json
```

然后重新在界面中设置。

## 如何完全卸载

1. 退出启动器。
2. 删除项目目录或 exe。
3. 可选：删除 `%APPDATA%\PhasmoLauncher`（配置 + 日志）。

不会残留服务、驱动或注册表项。

## 提交问题时请附上

- Windows 版本
- Python 版本（`python --version`）
- `python main.py --check` 的输出
- 日志文件：`%APPDATA%\PhasmoLauncher\logs\launcher.log`
- 复现步骤和实际现象

请勿在公开 issue 中粘贴 Steam 账号、令牌或加速器账号信息。
